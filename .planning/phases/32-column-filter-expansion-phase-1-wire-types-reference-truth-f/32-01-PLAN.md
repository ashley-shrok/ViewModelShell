**Operator vocabularies (SPEC Requirement 2, locked):**
- Text (6): `contains`, `equals`, `starts-with`, `ends-with`, `is-empty`, `is-not-empty`
- Number (10): `contains`, `equals`, `does-not-equal`, `greater-than`, `greater-than-or-equal`, `less-than`, `less-than-or-equal`, `between`, `is-empty`, `is-not-empty`
- Date (7): `contains`, `is`, `before`, `after`, `in-range`, `is-empty`, `is-not-empty`
- Fixed-set (5): `contains`, `is`, `is-not`, `is-empty`, `is-not-empty`
- Yes-no (5): `contains`, `is-true`, `is-false`, `is-empty`, `is-not-empty`

**FilterDescriptor semantics (SPEC Requirement 3 + D-03):**
- `rules: FilterRule[]` — ordered list; combined by `joiner`
- `joiner: "all-of" | "any-of"` — all-of = every rule matches; any-of = any rule matches
- No short-circuit per SPEC Requirement 6: every rule is evaluated regardless (simpler, easier to test)
- Rule with no value (is-empty, is-not-empty, is-true, is-false): `value` field is absent, NOT null

**matchesFilter semantics (SPEC Requirement 6, locked):**
- `contains` on every kind: match against displayString, case-insensitive, strip currency/comma/period before compare when `ignore-punctuation` matchingHint is set on the column
- `is-empty` / `is-not-empty`: rawValue === null / undefined / "" is empty; whitespace-only is NOT empty
- Number operators (equals, does-not-equal, gt, gte, lt, lte, between): compare rawValue as number
- Date operators (is, before, after, in-range): string comparison of rawValue vs rule value (ISO sort property — D-03)
- Fixed-set `is` / `is-not`: string equality on rawValue
- Yes-no `is-true` / `is-false`: boolean comparison on rawValue

**Signature decision (Claude's Discretion from CONTEXT):** `matchesFilter(descriptor: FilterDescriptor, rawValue: unknown, displayString: string, kind: ValueKind): boolean`. ValueKind is a separate arg (not embedded in descriptor — descriptor is the filter instance; kind is the column schema property). The matchingHints are passed as an optional final arg: `matchingHints?: MatchingHint[]`. Full signature: `matchesFilter(descriptor: FilterDescriptor, rawValue: unknown, displayString: string, kind: ValueKind, matchingHints?: MatchingHint[]): boolean`.
