<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Parity harness → backends | The harness sends the same requests to every backend and diffs responses. A backend that silently returned a different response body would be caught by the diff, but ONLY if the branch runs. Task 1's fix + Task 3's tripwires close the "branch didn't run" defect class. |
| Fixture JSON → parity/run.ts field consumption | If the fixture declares a field the harness ignores (e.g., an unknown field name), the intended branch silently doesn't fire. The `expectBodyContains: ["stale_client"]` tripwire declares a substring only the correct branch emits — mis-configuration fails loudly. |
| Cross-backend wire consistency | .NET StaleClientException (via ShellExceptionFilter mapping) + TS factory's jsonResponse must produce byte-identical wire envelopes for the message field's structure (both are `{ok: false, errors: [{message, code: "stale_client"}]}`) — parity diffs the structure with compareIgnoreFields for the message-text discrepancy. |
