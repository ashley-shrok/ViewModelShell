Add `CheckboxNode.variant: "checkbox" | "switch"` — a visual-only render mode. Falls back to standard checkbox render on adapters that don't know the variant (graceful degradation).

Output: `CheckboxNode.variant` axis exists on both backends; CSS restyles the checkbox mark into a track+thumb slider; a11y is intact; existing checkbox consumers unchanged.
