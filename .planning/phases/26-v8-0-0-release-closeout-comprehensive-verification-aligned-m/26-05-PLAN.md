    Re-run the ancestor check after reconciliation:
    ```
    git merge-base --is-ancestor v8.0.0 main && echo "v8.0.0 is on main" || echo "STILL STRANDED — SURFACE TO OPERATOR"
    ```
    Must print `v8.0.0 is on main` before this task completes.
