<objective>
Audit `viewmodel-shell/agent-skill.md` for v8.0.0 accuracy. Every v8.0 addition (Phase 23 foundations + Phase 24 primary composites + Phase 25 secondary composites) is checked against the concerns the skill manual actually covers — wire dispatch shape, response envelope, side-effect verbs, error codes, polling semantics, non-blocking dispatch, lookup fields, files, chart data, and versioning. Anything that has changed at those seams gets edited into `viewmodel-shell/agent-skill.md`, then byte-copied to `viewmodel-shell-dotnet/AgentSkill.md`. Parity gate proves both source + both served HTTP copies remain byte-identical.

Purpose: The agent-skill.md is the operator manual for wire-driving agents (`curl`, `WebFetch`, LLMs). AGENTS.md maintainer rule: "any change to the wire shape, response envelope, side-effect verb set, error code vocabulary, or polling semantics MUST update `viewmodel-shell/agent-skill.md` in the same change, then re-copy to `viewmodel-shell-dotnet/AgentSkill.md`." Phase 26 is the aligned major-line publish moment for v8.0.0 — even if the audit result is no-op (highly likely: agent-skill by convention does NOT enumerate node types, and v8.0 is additive+1-rename at the wire level with the protocol token unchanged at `viewmodel-shell/1.0`), the audit is on-the-record so the operator + future maintainers know the check was actually performed.

Output: Either an unchanged agent-skill (with audit reasoning recorded) OR precise edits applied to BOTH byte-mirrored copies + parity gate green.
</objective>
