Concrete target state:
1. The shim exports a function `mockFetch(input: RequestInfo, init?: RequestInit): Promise<Response>` that the ShellOptions.transport or global `fetch` override calls.
2. On GET → return a valid initial response.

Do NOT skip the validator call for "the page doesn't render invalid trees anyway" — that's exactly the false confidence the banked lesson warns against.
