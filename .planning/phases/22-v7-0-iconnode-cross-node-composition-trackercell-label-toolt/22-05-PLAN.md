<objective>
Complete ICON-06 by swapping the TrackerCell renderer's tooltip mechanism from `el.title = ...` (browser-native gray box) to the shipped 6.12.1 `.vms-tooltip-host` singleton (styled bubble). The wire-type rename landed in Plan 03; this plan is the render-path swap.

**Dependency:** Plan 03 must have landed (TrackerCell.label → TrackerCell.tooltip on both TS + .NET wire types). This plan modifies the browser renderer that reads that field — the field must exist under its new name before this plan touches the read.
