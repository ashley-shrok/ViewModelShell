<risk_summary>
- **The AGENTS.md #9 gap** — IconName is where the 38th open union would be born. TS closed unions default to `string?` on the .NET twin because there's no compiler enforcement across the boundary. This plan MUST land IconName as a real .NET enum with a converter; otherwise the twin silently accepts strings the TS side rejects, and the entire ICON-01 byte-identical contract collapses. The greps in acceptance criteria are the tripwire.
- **Positional-record parameter placement** — adding a positional parameter with a default at the END of an existing record IS source-compatible for named-argument callers but MAY break positional callers (a caller passing 12 positional args to a 12-parameter record now sees 13 parameters and one may fall in an unexpected slot if any existing default falls after the new one). The plan's approach: place `Icon` at the very end of each parameter list. If a demo/test callsite breaks compilation (Task 22-02-07 will surface this), fix the callsite by naming arguments, not by reordering framework record parameters.
- **Message drift** — Plan 01's message MUST match Plan 02's message. The `grep -c "icon-only ButtonNode requires tooltip"` acceptance criterion catches drift on each side; parity (Plan 07) catches cross-side drift via byte-diff.
</risk_summary>
