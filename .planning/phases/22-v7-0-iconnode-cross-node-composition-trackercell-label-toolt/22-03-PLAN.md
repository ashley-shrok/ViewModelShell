Land the ONE breaking wire change for v7.0.0 — rename `TrackerCell.label` → `TrackerCell.tooltip` on both backends — as a pure type-side rename. The renderer swap to the styled TOOL-01 tooltip infrastructure lives in Plan 05 (browser.ts) and depends on this rename landing first.

Landing it in Wave 1 as a self-contained type change gives the render-path swap (Plan 05) a clean base to build on and gives parity (Plan 07) a stable wire to assert against.

Output: field renamed on both backends, TSDoc/XML-doc updated (aria-label derivation and the mention of the tooltip infrastructure), one dedicated .NET test file proving the wire shape (tooltip present ⇒ `"tooltip":"x"`; tooltip absent ⇒ absent from JSON per WhenWritingNull) and that the old field name is compile-time gone.

```typescript
export interface TrackerCell {
  state?: "success" | "danger" | "warning" | "muted";
  /** Optional hover label for this bucket (e.g. "2026-07-15 14:22 UTC · Success").
   *  Rendered as the cell's native tooltip AND its aria-label, so the strip's
   *  meaning is carried by TEXT, not color alone — the a11y + agent-legibility
   *  channel a color-only glyph strip could never provide. */
  label?: string;
  /** Optional click-through: dispatches this action when the bucket is clicked or
   *  keyboard-activated ... */
  action?: ActionEvent;
}
```
