## 7.0.0 — <today's date>

### New
- **IconNode primitive** (ICON-01, ICON-02, ICON-03) — first-class icon support via a closed-union `name` from the bundled Lucide subset (~102 glyphs; see wire-type source for the full member list). Optional `size` ("xs"|"sm"|"md"|"lg"|"xl") and `tone` (semantic tint from the framework's tone axis). Optional `label` toggles decorative (`aria-hidden`) vs meaning-carrying (`role="img"` + `aria-label`) rendering. Framework owns the SVG payloads + all appearance + a11y; the wire carries only the name.
- **Cross-node `icon?: IconName`** (ICON-04) on ButtonNode, LinkNode, SectionNode, BadgeNode, and ListItemNode — leading icon rendered at host-appropriate size (Button/Link/Badge/ListItem lead with sm/xs; Section lead xl for the Hestia card use case). Host owns the appearance axis; the prop carries content only.
- **Icon-only-button walker rule** (ICON-05) — an icon-only ButtonNode without a tooltip now fails tree-validation with `code:"invalid_tree"` and the exact message `icon-only ButtonNode requires tooltip (used as aria-label)`. The tooltip becomes the button's aria-label.
- **`.vms-icon*` CSS classes** — token-driven size + tone modifiers on the base `.vms-icon`; `stroke="currentColor"` on the SVG inherits color from tone tokens.

### Breaking
- **`TrackerCell.label` → `TrackerCell.tooltip`** (ICON-06) — wire-field rename. Same type (`string?`), same semantics. Renderer swapped from `el.title = …` (browser-native gray box) to the shipped 6.12.1 styled tooltip infrastructure (body-appended `.vms-tooltip-host` singleton — same UX as ButtonNode.tooltip / TableColumn.tooltip). See MIGRATION.md for the consumer one-liner.

### TUI
- Icons dropped in TUI v1 (ICON-07) — @experimental scope, not-invested-in. `IconNode` renders as nothing; cross-node `icon?:` props are ignored. No unicode-fallback map.

### Parity
- FeatureProbe `buildVm` extended in both backends to exercise every icon surface + the icon-only-button walker + the renamed TrackerCell.tooltip; `expectBodyContains` coverage tripwires per branch.
